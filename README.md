## About

This is a browser-based fun game built with HTML, CSS, JavaScript, 3D models, and sound effects. No installation needed — just open the link and play.

## Features

- 🎮 Simple browser-based gameplay, playable on desktop and mobile
- 🔊 Full sound effects (traffic, crowd, animal sounds, and more)
- 🧊 3D models for realistic visuals
- 💥 Chaotic, funny mechanics — crash, dodge, and cause mayhem as a runaway cow

## Tech Stack

- HTML / CSS / JavaScript
- 3D assets (`.glb`)
- Custom font (Baloo Da 2)
- PHP (for leaderboard — works only on PHP-enabled hosting, not on GitHub Pages)

## Project Structure

```
gorur-gari-funney-game/
├── index.html              # Main entry point
├── admin.php                # Admin panel
├── lb.php / lb.json         # Leaderboard logic
├── config.json               # Game configuration
├── all glb/                  # 3D model files
├── all jpg/                  # Image assets
├── *sound folders*/          # Sound effects
└── BalooDa2-ExtraBold.ttf    # Custom font
```

## Note

The leaderboard feature (`lb.php`) requires PHP and a server — it will not work on GitHub Pages since GitHub Pages only serves static files. For full functionality including leaderboard, host the game on a PHP-enabled server (e.g. cPanel hosting).
